具体的组织架构包含以上两张图片，在议题中下载相关代码。
其中，carla下载版本为0.9.15，需要配套使用python3.7.9,可在相关网页搜索下载，亦或者借助命令行文件。
值得注意的是，carla官网的下载会直接跳转到说明文档，具体操作以说明文档为准，除了CARLA的主要安装包后，建议下载AdditionalMaps_0.9.16.zip,不用担心地图文件与主程序的版本不一致。
https://github.com/carla-simulator/carla/releases/tag/0.9.15/为carla 0.9.15 的下载链接，为何不使用最新版本，是因为carla版本与补丁版本不一致。
